2주차 - 실습 환경 구축과 버전 관리 기초

학습 목표
- WSL2와 Ubuntu를 이용해 리눅스 실습 환경을 구축한다.
- 리눅스 명령어로 파일과 디렉터리를 관리한다.
- Git을 이용해 작업 내용을 버전별로 저장하고 관리한다.
- GitHub에 저장소를 만들고 작업 내용을 공유한다.

학습 내용

1. 가상화와 실습 환경
서버는 다른 컴퓨터나 프로그램에 서비스를 제공하는 역할을 한다. 가상화는 하나의 컴퓨터에서 여러 환경을 사용할 수 있게 해 주는 기술이다.

WSL2를 이용하면 Windows에서 Ubuntu와 같은 리눅스 환경을 사용할 수 있다. 별도의 가상 머신보다 가볍게 리눅스 명령어를 실습할 수 있다는 장점이 있다.

2. 리눅스 기본 명령어
- `pwd`: 현재 작업 중인 디렉터리 확인
- `ls`: 파일과 디렉터리 목록 확인
- `cd`: 디렉터리 이동
- `mkdir`: 새 디렉터리 생성
- `nano`: 터미널에서 파일을 작성하거나 수정

3. Git을 이용한 버전 관리
Git은 파일의 변경 내용을 기록하고 이전 버전과 비교할 수 있게 해 주는 도구이다. 커밋으로 변경 사항을 저장하고, 브랜치를 이용하면 기존 작업과 분리해서 새로운 작업을 진행할 수 있다.

주요 명령어는 다음과 같다.

```bash
git status
git add .
git commit -m "작업 내용"
git log --oneline
git branch
git switch -c feature/test
```

4. GitHub
GitHub는 Git 저장소를 온라인에 올려 보관하고 다른 사람과 공유할 수 있는 플랫폼이다. 저장소를 만들고 작업 내용을 푸시하면 인터넷에서 프로젝트를 확인할 수 있다.

```bash
git push
git clone 저장소주소
```

실습 정리
이번 주에는 개발에 필요한 리눅스 환경을 준비하고 기본 명령어를 익혔다. Git으로 변경 사항을 기록하고 GitHub에 저장소를 만들어 작업 내용을 공유하는 방법도 배웠다.
