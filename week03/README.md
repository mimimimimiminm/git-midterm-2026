3주차 - 셸 스크립팅

학습 목표
- 반복적으로 사용하는 명령어를 셸 스크립트로 작성한다.
- 셸 스크립트의 실행 권한과 shebang을 이해한다.
- 환경 변수와 조건문을 이용해 실행 환경을 확인한다.
- 명령어의 실행 결과를 이용해 오류 상황을 처리한다.

학습 내용

1. 셸 스크립트와 자동화
셸 스크립트는 여러 명령어를 파일에 작성해 한 번에 실행할 수 있도록 만든 것이다. 같은 작업을 반복해야 할 때 스크립트를 이용하면 시간을 줄이고 실수를 줄일 수 있다.

2. 셸 스크립트 작성과 실행
Bash 스크립트의 첫 줄에는 보통 `#!/bin/bash`를 작성한다. 이 부분을 shebang이라고 하며, 어떤 프로그램으로 스크립트를 실행할지 지정한다.

```bash
#!/bin/bash
echo "Hello, DevOps!"
```

실행 권한을 설정한 다음 스크립트를 실행할 수 있다.

```bash
chmod u+x start.sh
./start.sh
```

3. 경로와 환경 변수
스크립트를 실행할 때는 현재 작업 위치와 파일이 있는 경로를 확인해야 한다. 경로를 잘못 지정하면 파일을 찾지 못할 수 있다.

환경 변수는 프로그램 실행에 필요한 설정값을 전달할 때 사용할 수 있다.

4. 조건문과 오류 처리
조건문을 이용하면 특정 프로그램이 설치되어 있는지 확인하거나 실행 결과에 따라 다른 작업을 진행할 수 있다.

```bash
if command -v python3 >/dev/null 2>&1; then
    echo "Python3가 설치되어 있습니다."
else
    echo "Python3가 설치되어 있지 않습니다."
    exit 1
fi
```

`exit 1`은 스크립트가 오류 상태로 종료되었음을 나타낸다. 오류 메시지를 출력하는 것과 오류 상태로 종료하는 것은 서로 다르다.
